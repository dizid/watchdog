What is Google Antigravity 2.0?

Concept

Antigravity 2.0 is Google's agent-first coding platform — not an IDE plugin, not a chatbot. It's a complete rethink of how software gets built.

The paradigm shift: You stop writing code. You become a project manager who delegates to a team of AI agents running in parallel.

Instead of prompting a single AI one task at a time, Antigravity 2.0 spins up a manager agent that decomposes your goal into subtasks, then dispatches specialized sub-agents — one for frontend, one for backend, one for tests — all running simultaneously.

The Three Components

Architecture

Antigravity 2.0 ships as three separate tools. You don't need all three — pick what fits your workflow.

Component What it is Best for
Desktop App VS Code fork with deep agent integration, chat-first interface Visual workflow, beginners, managing multiple agent sessions
CLI Go-based terminal tool — replaces Gemini CLI (deprecated June 18) Terminal-native developers, scripting, CI/CD pipelines
SDK Python, TypeScript, Go libraries for programmatic agent control Embedding agents in your own tools, custom automation, CI integration
Recommendation: Start with the CLI. It works alongside VS Code, Vim, JetBrains — whatever editor you already use. The desktop app is optional.

Coming from Gemini CLI? It's deprecated as of June 18, 2026. Migrate in one command:

antigravity migrate --from-gemini-cli

Getting Started

Hands-on
1
Install the CLI

One-liner install for Linux:

# Linux
curl -fsSL https://antigravity.dev/install.sh | bash

# macOS
brew install google/antigravity/antigravity

# Windows
winget install Google.Antigravity
2
Authenticate

Opens Google OAuth in your browser.

antigravity auth login
3
Configure your project

Create .antigravity.yaml in your project root:

model: gemini-3.5-flash
sandbox: true          # run code in isolated Linux env
auto_approve: false  # IMPORTANT: review changes before they apply
test_command: npm test
Beginner tip: Always start with auto_approve: false. You'll see every file change before it's written. Once you trust the agent's judgment on your codebase, you can flip it to true.
4
Run your first task

Natural language — describe the goal, not the steps.

# Run from inside your project directory
antigravity "Add input validation to the login form and write tests for it"

The manager agent will plan the work, dispatch sub-agents, and present you with a diff to approve before anything is written to disk.

Multi-Agent Orchestration

Core Feature

This is the killer feature. Single-agent tools hit context window limits on large tasks. Antigravity solves it with a manager + sub-agent hierarchy.

How it works:
Manager agent receives your goal → decomposes into subtasks → dispatches parallel specialized agents (frontend, backend, test) → collects results → presents unified diff.

You can also use the SDK to build custom orchestration:

from antigravity import Agent, Task

# Instantiate an agent (uses gemini-3.5-flash by default)
agent = Agent(model="gemini-3.5-flash")

# Define a task with optional constraints
task = Task(
    description="Refactor the authentication module for better error handling",
    workspace="/path/to/project",
    constraints=["Don't modify the public API", "Keep existing tests passing"]
)

result = agent.execute(task)
print(result.summary)

Managed Agents (cloud execution) let you spin up an agent in an isolated Linux sandbox with a single API call — no local environment setup needed:

from antigravity import ManagedAgent

# Runs in Google's isolated Linux environment
agent = ManagedAgent.create(
    model="gemini-3.5-flash",
    tools=["code_execution", "file_management", "web_browse"]
)
result = agent.run("Analyze this codebase and generate a test coverage report")
📁
File management Agents read, write, and organize files across your project.
🌍
Web browsing Agents can fetch docs, check APIs, and look up current info.
🔧
Function calling Connect agents to your own tools and internal APIs.
📊
Structured output Get typed JSON responses, not just raw text.

Slash Commands & Controls

Power User

Antigravity ships with built-in slash commands and control mechanisms to shape how agents behave.

Command / Feature What it does When to use
/goal Silent execution mode — agent works without asking for confirmations Trusted tasks on non-critical code
/grill-me Agent asks clarifying questions before starting, then proceeds Ambiguous tasks where requirements need tightening
/browser Opens a headless browser for visual testing and screenshots Frontend work, UI bug verification
/voice Native voice input — speak your task instead of typing Mobile use, hands-busy workflows

JSON Hooks (Interceptors) — add checkpoints before risky operations:

# .antigravity.yaml — require human approval before deleting files
hooks:
  - event: file_delete
    action: require_approval
  - event: schema_migration
    action: require_approval
  - event: git_push
    action: block  # never let agents push without you

Scheduled Tasks — cron-like automation:

# Run dependency audit every Monday at 9am
scheduled_tasks:
  - cron: "0 9 * * 1"
    task: "Audit npm dependencies for security vulnerabilities and open a PR with fixes"

  - cron: "0 8 * * *"
    task: "Run full test suite and post results to Slack #dev-alerts"
Integration tip: Antigravity connects natively to Google AI Studio, Android Studio, and Firebase — you don't need to configure these manually if you're already signed into Google.
